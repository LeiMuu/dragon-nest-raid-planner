# 龍之谷｜龍巢穴建團管理器

龍之谷懷舊服海龍巢穴的建團工具。從公會成員、固定與候補團隊，到 2R／3R／7R 的站位分配，最後產生可直接貼到 Discord 的出團訊息。

**線上使用：** https://<你的帳號>.github.io/dragon-nest-raid-planner/

## 功能

- **成員設定**：成員可擁有多個職業（可重複、可加備註），表格呈現並支援快速搜尋
- **團隊設定**：建立固定與候補的候選池，可複製團隊、設定職業限制
- **建立出團**：勾選出席者、一鍵補滿 8 人，並用示意圖點選位置分配成員
- **出團紀錄**：編輯、複製舊團設定，預覽並複製 Discord 訊息
- **基本設定**：自訂職業、職業限制 SET、各位置偏好職業、資料匯出與匯入

## 支援的副本與回合

| 副本 | 人數 | 分配回合 |
|---|---|---|
| 海龍巢穴外圍 | 5-8 | 2R 暴走島-魔法石、3R 熔岩島-站台 |
| 海龍巢穴核心 | 5-8 | 7R 海龍-砲台 |
| 海龍巢穴經典 | 5-8 | 2R、3R、7R |
| 海龍巢穴地獄 | 5-8 | 7R 砲台、7R 冰封砲台 |

## 快速開始

1. 在「成員設定」設定公會名稱並新增成員
2. 在「團隊設定」建立常用團隊
3. 在「建立出團」選團隊、勾選出席者並分配各回合位置
4. 儲存後到「出團紀錄」預覽並複製訊息

## 資料與備份

所有資料只存在你自己的瀏覽器（localStorage），不會上傳到任何伺服器。清除瀏覽器資料、換裝置或換瀏覽器都會看不到舊資料，請定期到「基本設定」匯出 JSON 備份，需要時再匯入。

## 本機執行

單一 `index.html`，不需要建置，直接用瀏覽器開啟即可。
